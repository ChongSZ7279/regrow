# ReGrow - Food Rescue Prototype (Flutter)

## Overview
ReGrow is a prototype mobile app to connect surplus food donors (households & restaurants) with NGOs, volunteers and community fridges to rescue edible food and reduce waste.

## Requirements
- Flutter SDK (>= 3.x)
- Dart SDK
- Android/iOS device or emulator

## Setup
1. Create a new Flutter project (or replace `lib/` with the files provided).
   ```bash
   flutter create regrow_flutter
